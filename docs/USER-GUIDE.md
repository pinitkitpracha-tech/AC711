# คู่มือผู้ใช้ AC711 — ระบบบริหารร้านอะไหล่และสาขาบนคลาวด์

www.ac711.com · ค่าบริการรายปี 18,000 บาท (ไม่รวม VAT 7%) ทดลองใช้ฟรี 30 วัน ครบทุกฟีเจอร์

## 1. เริ่มต้นใช้งาน

1. เปิด www.ac711.com กด **สมัครใช้บริการ** กรอกชื่อร้าน ชื่อผู้สมัคร อีเมล เบอร์โทร จังหวัด และจำนวนสาขา
2. อ่านและกดยอมรับ **ประกาศความเป็นส่วนตัว (PDPA)** และข้อกำหนดการใช้บริการ (ช่องรับข่าวสารเลือกได้ ไม่บังคับ)
3. เปิดอีเมลที่ระบบส่งให้ จะมี **ชื่อผู้ใช้ (อีเมลของคุณ) รหัสผ่านชั่วคราว และรหัสร้าน** กดปุ่ม **ยืนยันอีเมลและเริ่มใช้งาน** (ลิงก์ใช้ได้ครั้งเดียว)
4. กลับมาหน้า **เข้าสู่ระบบ** กรอกอีเมลและรหัสผ่านที่ได้รับ ระยะทดลองใช้ 30 วันเริ่มนับตั้งแต่วันยืนยันอีเมล
5. แนะนำให้เปลี่ยนรหัสผ่านทันที: กดชื่อผู้ใช้มุมขวาบน → **เปลี่ยนรหัสผ่าน**

ลืมรหัสผ่าน: หน้าเข้าสู่ระบบ → **ลืมรหัสผ่าน** → กรอกอีเมล → กดลิงก์ในอีเมล (อายุ 60 นาที) ตั้งรหัสใหม่

## 2. ตั้งค่าร้านก่อนเริ่มขาย (เมนู ตั้งค่า)

- **ข้อมูลร้าน**: ชื่อร้าน ที่อยู่ เลขประจำตัวผู้เสียภาษี 13 หลัก (พิมพ์หรือวางทีเดียวได้) PromptPay ข้อความท้ายใบเสร็จ อัตรา VAT
- **จำนวนสาขา**: ระบุจำนวนแล้วกด "ใช้จำนวนสาขานี้" ระบบสร้างรหัสสาขา 0001, 0002 … ให้ (สำนักงานใหญ่คือ 0000) ตั้งชื่อ ที่อยู่ เบอร์โทรของแต่ละสาขาได้ที่เมนู **ตั้งค่าสาขา**
- **พนักงาน**: เพิ่มผู้ใช้ กำหนดบทบาท (ผู้จัดการ POS คลัง จัดซื้อ บัญชี การตลาด HR) สาขาประจำ และ PIN สำหรับสลับผู้ใช้หน้า POS
- **สิทธิ์การใช้งาน** (เมนู บุคคล → สิทธิ์): เปิด/ปิดได้ทั้งเมนูหลักและ **เมนูย่อยทุกแท็บ** ต่อบทบาท และตั้งเฉพาะรายบุคคลได้จากปุ่ม "สิทธิ์" ของพนักงานแต่ละคน
- **พนักงานเข้าระบบ**: ใช้ชื่อผู้ใช้และรหัสผ่านที่เจ้าของตั้งให้ ถ้าระบบถามหา **รหัสร้าน** (เช่น S1001) ให้กรอกรหัสที่อยู่ในอีเมลยืนยันของเจ้าของร้าน

## 3. นำเข้าข้อมูลตั้งต้น (การ์ด "นำเข้าข้อมูล" ในแต่ละเมนู)

ทุกเมนูมีการ์ด **นำเข้าข้อมูล** และ **ส่งออกข้อมูล** ด้านล่าง กด "ไฟล์ตัวอย่าง" เพื่อดาวน์โหลด CSV ต้นแบบ กรอกด้วย Excel/Google Sheets (บันทึกเป็น CSV UTF-8) แล้วอัปโหลด ระบบแสดงตัวอย่างให้ตรวจก่อนนำเข้าจริง

| เมนู | นำเข้าได้ |
|---|---|
| สินค้า | ทะเบียนสินค้า (SKU ชื่อ หมวด ยี่ห้อ หน่วย ต้นทุน ราคาปลีก/ส่ง/ออนไลน์ บาร์โค้ด) |
| ลูกค้า | ลูกค้า (ชื่อ โทร ประเภท ที่อยู่ เลขผู้เสียภาษี เครดิต) |
| จัดซื้อ | ผู้จำหน่าย |
| สต็อก | จุดสั่งซื้อ Min/Max ต่อสาขา และ **ยอดยกมาสต็อก** (ผลนับสต็อกจริงวันเริ่มใช้) |
| บัญชี | **ลูกหนี้ยกมา** และ **เจ้าหนี้ยกมา** (บิลค้างชำระก่อนเริ่มใช้ระบบ) |
| บุคคล | พนักงาน (ทะเบียน HR) |
| ตั้งค่าสาขา | สาขา |

ลำดับที่แนะนำ: สินค้า → ผู้จำหน่าย → ลูกค้า → ยอดยกมาสต็อก → ลูกหนี้/เจ้าหนี้ยกมา

## 4. ขายหน้าร้าน (POS)

- ค้นหาสินค้าด้วยชื่อ SKU หรือยิงบาร์โค้ด รายการในตะกร้าแสดง 2 บรรทัด (รหัส / ชื่อ) **แก้ชื่อสินค้าเฉพาะบิลนี้ได้** โดยไม่กระทบทะเบียน กดปุ่มลบท้ายรายการเพื่อเอาออก
- กด **ชำระเงิน** พิมพ์ยอดรับเงินจากแป้นพิมพ์ได้โดยตรง เลือกเงินสด / โอน / PromptPay (แสดง QR) / บัตร / ขายเชื่อ
- **ชำระบางส่วน**: ติ๊ก "ชำระบางส่วน" ใส่ยอดที่รับ ระบบสร้างลูกหนี้คงค้างให้ และกลับมา **รับชำระเงิน** ได้จากปุ่มสถานะในบิล จนครบจำนวน ทุกงวดออกใบเสร็จรับเงินได้
- พิมพ์ **ใบเสร็จอย่างย่อ** (เครื่องพิมพ์ความร้อน 58/80 มม. ผ่านการพิมพ์ของเบราว์เซอร์) หรือ **ใบกำกับภาษีเต็มรูป (A4)** จากปุ่มในหน้าใบเสร็จ ถ้าต้องการชื่อ/เลขผู้เสียภาษีผู้ซื้อ ให้เลือกลูกค้าในระบบหรือกรอกในช่อง "ใบกำกับ" ตอนชำระเงิน
- ปุ่มสถานะ **ชำระแล้ว / ค้างบางส่วน / รับชำระเงิน** มีในทุกเอกสารซื้อ-ขาย กดแล้วไปหน้ารับ/จ่ายชำระของคู่ค้ารายนั้นทันที (ชำระบางส่วนได้ทั้งลูกหนี้และเจ้าหนี้)

## 5. เมนูหลังร้าน

- **รายรับ**: ยอดขายรายวันแบบรายบิล เรียงตามเวลา ค้นหาได้ เลือกช่วง วันนี้ / เดือนนี้ / ปีนี้ / ปีที่แล้ว (พ.ศ.) หรือกำหนดเอง
- **สต็อก**: เห็นของทุกสาขา โอนย้ายระหว่างสาขา แจ้งเตือนต่ำกว่า Min และใกล้หมดอายุ
- **จัดซื้อ**: ใบสั่งซื้อ รับสินค้า ค่าใช้จ่าย (การรับสินค้าต้องผ่านการอนุมัติของผู้จัดการ)
- **บัญชี**: ลูกหนี้ เจ้าหนี้ สมุดรายวัน งบกำไรขาดทุน ภ.พ.30 ปิดงวด
- **พยากรณ์ / AI**: แนะนำจุดสั่งซื้อ พยากรณ์ยอดขาย และผู้ช่วย AI ถาม-ตอบจากตัวเลขในร้าน
- **ประวัติการแก้ไข** (เจ้าของร้าน/ผู้จัดการ): กดชื่อผู้ใช้มุมขวาบน → "ประวัติการแก้ไขของพนักงานทั้งหมด" ดูว่าใครแก้อะไร เมื่อไร กรองรายคนได้

## 6. เริ่มใช้งานจริงหลังทดลอง

1. ตั้งค่าร้าน → **ส่งออกข้อมูลทั้งหมด (JSON)** เก็บไว้ก่อนเสมอ
2. ตั้งค่าร้าน → **ลบข้อมูลทดสอบระบบ** เลือก "ลบเฉพาะรายการเคลื่อนไหว" (คงสินค้า ลูกค้า ผู้จำหน่ายไว้) หรือ "ลบทั้งหมด" แล้วพิมพ์ **ลบ** ยืนยัน
3. นำเข้ายอดยกมา (ข้อ 3) แล้วเริ่มขาย
4. **กู้คืนจากไฟล์สำรอง**: การ์ดเดียวกันรับไฟล์ JSON ที่ส่งออกไว้ แทนที่ข้อมูลทุกตารางในไฟล์ (ยกเว้นบัญชีผู้ใช้และการเชื่อมต่อ) พิมพ์ **กู้คืน** ยืนยัน

## 7. แพ็กเกจรายปี การชำระเงิน และใบกำกับภาษี

- ป้าย "ทดลองใช้ เหลือ N วัน" มุมขวาบน กดเพื่อดูแพ็กเกจ · ระบบส่งอีเมลเตือนก่อนหมดอายุ 7 วันและ 1 วัน
- เมื่อครบกำหนดหรือถูกระงับ ระบบล็อกการใช้งาน **ข้อมูลของร้านไม่หาย** หน้าเข้าสู่ระบบจะแสดงหน้าแพ็กเกจให้เจ้าของร้าน **แจ้งชำระเงิน** ได้ทันที
- โอนเงิน 19,260 บาท (18,000 + VAT 7%) ตามบัญชีที่แสดง แล้วกด **แจ้งชำระเงิน** แนบสลิป ระบุที่อยู่ออกใบกำกับภาษี · นิติบุคคลที่หัก ณ ที่จ่าย 3% ติ๊กช่อง "หัก ณ ที่จ่าย" ระบบปรับยอดโอนเป็น 18,720 บาท และส่งหนังสือรับรองการหักภาษีให้ผู้ให้บริการ
- ผู้ดูแลระบบตรวจสอบและอนุมัติภายใน 1 วันทำการ ระบบต่ออายุ **+1 ปีนับจากวันหมดอายุเดิม** ออกใบกำกับภาษี/ใบเสร็จ (เปิดจากหน้าแพ็กเกจ พิมพ์หรือบันทึก PDF ได้) และส่งอีเมลแจ้ง

## 8. ความปลอดภัยและข้อมูลส่วนบุคคล

- รหัสผ่านทุกบัญชีถูกเข้ารหัสแบบทางเดียว การรับส่งข้อมูลผ่าน HTTPS สิทธิ์แยกตามบทบาทและสาขา
- ข้อมูลลูกค้า/พนักงานที่ร้านบันทึก ร้านเป็นผู้ควบคุมข้อมูล AC711 เป็นผู้ประมวลผลตามคำสั่งของร้าน (ดูประกาศความเป็นส่วนตัวท้ายเว็บไซต์)
- ทุกการกระทำในระบบถูกบันทึก (ใคร ทำอะไร เมื่อไร) เพื่อการตรวจสอบและพัฒนาระบบ
- ส่งออกข้อมูลของร้านได้ทุกเมื่อ; ขอลบบัญชีได้ที่อีเมลฝ่ายขายที่แสดงบนเว็บไซต์
