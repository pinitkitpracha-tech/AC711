# คู่มือผู้ใช้ AC711 — ระบบบริหารร้านอะไหล่และสาขาบนคลาวด์

> คู่มือฉบับเต็มพร้อมภาพหน้าจอทุกฟังก์ชัน (เวอร์ชัน 1.0.26, 115 หน้า): [AC711-Manual-1.0.26.pdf](AC711-Manual-1.0.26.pdf)

www.ac711.com · ค่าบริการรายปี 18,000 บาท (ไม่รวม VAT 7%) ทดลองใช้ฟรี 30 วัน ครบทุกฟีเจอร์

## 1. เริ่มต้นใช้งาน

1. เปิด www.ac711.com กด **สมัครใช้บริการ** กรอกชื่อร้าน ชื่อผู้สมัคร อีเมล เบอร์โทร จังหวัด และจำนวนสาขา
2. อ่านและกดยอมรับ **ประกาศความเป็นส่วนตัว (PDPA)** และข้อกำหนดการใช้บริการ (ช่องรับข่าวสารเลือกได้ ไม่บังคับ)
3. เปิดอีเมลที่ระบบส่งให้ จะมี **ชื่อผู้ใช้ (อีเมลของคุณ) รหัสผ่านชั่วคราว และรหัสร้าน** กดปุ่ม **ยืนยันอีเมลและเริ่มใช้งาน** (ลิงก์ใช้ได้ครั้งเดียว)
4. กลับมาหน้า **เข้าสู่ระบบ** กรอกอีเมลและรหัสผ่านที่ได้รับ ระยะทดลองใช้ 30 วันเริ่มนับตั้งแต่วันยืนยันอีเมล
5. แนะนำให้เปลี่ยนรหัสผ่านทันที: กดชื่อผู้ใช้มุมขวาบน → **เปลี่ยนรหัสผ่าน**

ลืมรหัสผ่าน: หน้าเข้าสู่ระบบ → **ลืมรหัสผ่าน** → กรอกอีเมล → กดลิงก์ในอีเมล (อายุ 60 นาที) ตั้งรหัสใหม่

## 2. ตั้งค่าร้านก่อนเริ่มขาย (เมนู ตั้งค่า)

- **ข้อมูลร้าน**: ชื่อร้าน ที่อยู่ เลขประจำตัวผู้เสียภาษี 13 หลัก (พิมพ์หรือวางทีเดียวได้) PromptPay ข้อความท้ายใบเสร็จ อัตรา VAT
- **จำนวนสาขา**: ระบุจำนวนแล้วกด "ใช้จำนวนสาขานี้" ระบบสร้างรหัสสาขา 0001, 0002 … ให้ (สำนักงานใหญ่คือ 0000) ตั้งชื่อ ที่อยู่ เบอร์โทรของแต่ละสาขาได้ที่เมนู **ตั้งค่าสาขา**
- **พนักงาน**: เพิ่มผู้ใช้ กำหนดบทบาท (ผู้จัดการ POS คลัง จัดซื้อ บัญชี การตลาด HR) สาขาประจำ และ PIN สำหรับสลับผู้ใช้หน้า POS
- **สิทธิ์การใช้งาน** (เมนู บุคคล → สิทธิ์): เปิด/ปิดได้ทั้งเมนูหลักและ **เมนูย่อยทุกแท็บ** ต่อบทบาท และตั้งเฉพาะรายบุคคลได้จากปุ่ม "สิทธิ์" ของพนักงานแต่ละคน
- **พนักงานเข้าระบบ**: ใช้ชื่อผู้ใช้และรหัสผ่านที่เจ้าของตั้งให้ ถ้าระบบถามหา **รหัสร้าน** (เช่น S1001) ให้กรอกรหัสที่อยู่ในอีเมลยืนยันของเจ้าของร้าน

## 3. นำเข้าข้อมูลตั้งต้น (การ์ด "นำเข้าข้อมูล" ในแต่ละเมนู)

ทุกเมนูมีการ์ด **นำเข้าข้อมูล** และ **ส่งออกข้อมูล** ด้านล่าง กด "ไฟล์ตัวอย่าง" เพื่อดาวน์โหลด CSV ต้นแบบ กรอกด้วย Excel/Google Sheets (บันทึกเป็น CSV UTF-8) แล้วอัปโหลด ระบบแสดงตัวอย่างให้ตรวจก่อนนำเข้าจริง

| เมนู | นำเข้าได้ |
|---|---|
| สินค้า | ทะเบียนสินค้า (SKU ชื่อ หมวด ยี่ห้อ หน่วย ต้นทุน ราคาปลีก/ส่ง/ออนไลน์ บาร์โค้ด) |
| ลูกค้า | ลูกค้า (ชื่อ โทร ประเภท ที่อยู่ เลขผู้เสียภาษี เครดิต) |
| จัดซื้อ | ผู้จำหน่าย |
| สต็อก | จุดสั่งซื้อ Min/Max ต่อสาขา และ **ยอดยกมาสต็อก** (ผลนับสต็อกจริงวันเริ่มใช้) |
| บัญชี | **ลูกหนี้ยกมา** และ **เจ้าหนี้ยกมา** (บิลค้างชำระก่อนเริ่มใช้ระบบ) |
| บุคคล | พนักงาน (ทะเบียน HR) |
| ตั้งค่าสาขา | สาขา |

ลำดับที่แนะนำ: สินค้า → ผู้จำหน่าย → ลูกค้า → ยอดยกมาสต็อก → ลูกหนี้/เจ้าหนี้ยกมา

## 4. ขายหน้าร้าน (POS)

- ค้นหาสินค้าด้วยชื่อ SKU หรือยิงบาร์โค้ด รายการในตะกร้าแสดง 2 บรรทัด (รหัส / ชื่อ) **แก้ชื่อสินค้าเฉพาะบิลนี้ได้** โดยไม่กระทบทะเบียน กดปุ่มลบท้ายรายการเพื่อเอาออก
- กด **ชำระเงิน** พิมพ์ยอดรับเงินจากแป้นพิมพ์ได้โดยตรง เลือกเงินสด / โอน / PromptPay (แสดง QR) / บัตร / ขายเชื่อ
- **ชำระบางส่วน**: ติ๊ก "ชำระบางส่วน" ใส่ยอดที่รับ ระบบสร้างลูกหนี้คงค้างให้ และกลับมา **รับชำระเงิน** ได้จากปุ่มสถานะในบิล จนครบจำนวน ทุกงวดออกใบเสร็จรับเงินได้
- พิมพ์ **ใบเสร็จอย่างย่อ** (เครื่องพิมพ์ความร้อน 58/80 มม. ผ่านการพิมพ์ของเบราว์เซอร์) หรือ **ใบกำกับภาษีเต็มรูป (A4)** จากปุ่มในหน้าใบเสร็จ ถ้าต้องการชื่อ/เลขผู้เสียภาษีผู้ซื้อ ให้เลือกลูกค้าในระบบหรือกรอกในช่อง "ใบกำกับ" ตอนชำระเงิน
- ปุ่มสถานะ **ชำระแล้ว / ค้างบางส่วน / รับชำระเงิน** มีในทุกเอกสารซื้อ-ขาย กดแล้วไปหน้ารับ/จ่ายชำระของคู่ค้ารายนั้นทันที (ชำระบางส่วนได้ทั้งลูกหนี้และเจ้าหนี้)

## 5. เมนูหลังร้าน

- **รายรับ**: ยอดขายรายวันแบบรายบิล เรียงตามเวลา ค้นหาได้ เลือกช่วง วันนี้ / เดือนนี้ / ปีนี้ / ปีที่แล้ว (พ.ศ.) หรือกำหนดเอง
- **สต็อก**: เห็นของทุกสาขา โอนย้ายระหว่างสาขา แจ้งเตือนต่ำกว่า Min และใกล้หมดอายุ
- **จัดซื้อ**: ใบสั่งซื้อ รับสินค้า ค่าใช้จ่าย (การรับสินค้าต้องผ่านการอนุมัติของผู้จัดการ)
- **บัญชี**: ลูกหนี้ เจ้าหนี้ สมุดรายวัน งบกำไรขาดทุน ภ.พ.30 ปิดงวด
- **พยากรณ์ / AI**: แนะนำจุดสั่งซื้อ พยากรณ์ยอดขาย และผู้ช่วย AI ถาม-ตอบจากตัวเลขในร้าน
- **ใบเสนอราคา / ใบรับรถ** (อู่ซ่อมรถ): ดูหัวข้อ 10
- **งานรับประกัน / เคลม**: รถกลับมาเคลม เบิกอะไหล่ไม่คิดเงิน ลงบัญชีค่าใช้จ่ายรับประกัน เคลมต่อผู้จำหน่าย ดูหัวข้อ 11
- **CRM ติดตามลูกค้า**: งานติดตามหลังบริการ เตือนนัดบริการ ลูกค้า 360° ดูหัวข้อ 10
- **ประวัติการแก้ไข** (เจ้าของร้าน/ผู้จัดการ): กดชื่อผู้ใช้มุมขวาบน → "ประวัติการแก้ไขของพนักงานทั้งหมด" ดูว่าใครแก้อะไร เมื่อไร กรองรายคนได้

## 6. เริ่มใช้งานจริงหลังทดลอง

1. ตั้งค่าร้าน → **ส่งออกข้อมูลทั้งหมด (JSON)** เก็บไว้ก่อนเสมอ
2. ตั้งค่าร้าน → **ลบข้อมูลทดสอบระบบ** เลือก "ลบเฉพาะรายการเคลื่อนไหว" (คงสินค้า ลูกค้า ผู้จำหน่ายไว้) หรือ "ลบทั้งหมด" แล้วพิมพ์ **ลบ** ยืนยัน
3. นำเข้ายอดยกมา (ข้อ 3) แล้วเริ่มขาย
4. **กู้คืนจากไฟล์สำรอง**: การ์ดเดียวกันรับไฟล์ JSON ที่ส่งออกไว้ แทนที่ข้อมูลทุกตารางในไฟล์ (ยกเว้นบัญชีผู้ใช้และการเชื่อมต่อ) พิมพ์ **กู้คืน** ยืนยัน

## 7. แพ็กเกจรายปี การชำระเงิน และใบกำกับภาษี

- ป้าย "ทดลองใช้ เหลือ N วัน" มุมขวาบน กดเพื่อดูแพ็กเกจ · ระบบส่งอีเมลเตือนก่อนหมดอายุ 7 วันและ 1 วัน
- เมื่อครบกำหนดหรือถูกระงับ ระบบล็อกการใช้งาน **ข้อมูลของร้านไม่หาย** หน้าเข้าสู่ระบบจะแสดงหน้าแพ็กเกจให้เจ้าของร้าน **แจ้งชำระเงิน** ได้ทันที
- โอนเงิน 19,260 บาท (18,000 + VAT 7%) ตามบัญชีที่แสดง แล้วกด **แจ้งชำระเงิน** แนบสลิป ระบุที่อยู่ออกใบกำกับภาษี · นิติบุคคลที่หัก ณ ที่จ่าย 3% ติ๊กช่อง "หัก ณ ที่จ่าย" ระบบปรับยอดโอนเป็น 18,720 บาท และส่งหนังสือรับรองการหักภาษีให้ผู้ให้บริการ
- ผู้ดูแลระบบตรวจสอบและอนุมัติภายใน 1 วันทำการ ระบบต่ออายุ **+1 ปีนับจากวันหมดอายุเดิม** ออกใบกำกับภาษี/ใบเสร็จ (เปิดจากหน้าแพ็กเกจ พิมพ์หรือบันทึก PDF ได้) และส่งอีเมลแจ้ง

## 8. ความปลอดภัยและข้อมูลส่วนบุคคล

- รหัสผ่านทุกบัญชีถูกเข้ารหัสแบบทางเดียว การรับส่งข้อมูลผ่าน HTTPS สิทธิ์แยกตามบทบาทและสาขา
- ข้อมูลลูกค้า/พนักงานที่ร้านบันทึก ร้านเป็นผู้ควบคุมข้อมูล AC711 เป็นผู้ประมวลผลตามคำสั่งของร้าน (ดูประกาศความเป็นส่วนตัวท้ายเว็บไซต์)
- ทุกการกระทำในระบบถูกบันทึก (ใคร ทำอะไร เมื่อไร) เพื่อการตรวจสอบและพัฒนาระบบ
- ส่งออกข้อมูลของร้านได้ทุกเมื่อ; ขอลบบัญชีได้ที่อีเมลฝ่ายขายที่แสดงบนเว็บไซต์

## 10. อู่ซ่อมรถ: ใบเสนอราคา ใบรับรถ ใบเสร็จพร้อมรับประกัน และ CRM

ใช้ได้ทั้งร้านอะไหล่ที่มีงานติดตั้ง และอู่ซ่อมรถเต็มรูปแบบ ไม่ต้องเปิดโหมดพิเศษ เมนูอยู่ในกลุ่ม "หน้าร้าน"

### 10.1 รถของลูกค้า
- เมนู **ลูกค้า** → เปิดลูกค้า → การ์ด "รถของลูกค้า" กด **เพิ่มรถ** ได้หลายคัน (ทะเบียน จังหวัด ยี่ห้อ รุ่น ปี สี VIN เลขเครื่อง เลขไมล์)
- ค้นลูกค้าด้วยทะเบียนรถได้ทั้งในเมนูลูกค้า หน้าสร้างใบเสนอราคา และ CRM
- นำเข้าทะเบียนรถจาก CSV ได้ที่การ์ด "นำเข้าข้อมูล" ในเมนู ใบเสนอราคา/ใบรับรถ (จับคู่ลูกค้าด้วยเบอร์โทรหรือชื่อ)
- รถที่เคยมีงานซ่อมจะลบไม่ได้ ระบบซ่อนให้แทนเพื่อรักษาประวัติ
- **เลขตัวถัง (VIN) และเลขไมล์เป็นข้อมูลบังคับ**: เพิ่มรถใหม่ต้องมี VIN ทุกเอกสารรับซ่อม (ใบเสนอราคา ใบรับรถ ใบเสร็จ ใบรับงานเคลม) ต้องระบุเลขไมล์ปัจจุบัน และจะพิมพ์ VIN กับเลขไมล์บนเอกสารเสมอ รถเก่าที่ยังไม่มี VIN ระบบจะเตือนให้แก้ไขก่อนออกเอกสาร

### 10.2 ขั้นตอนงานซ่อม (เมนู ใบเสนอราคา / ใบรับรถ)
1. **ใบเสนอราคาใหม่** ฟอร์มแสดงเหมือนหน้ากระดาษ A4 (หัวร้าน เลขที่ วันที่ ลูกค้า รถ รายการ ลายเซ็น) ตารางรายการเริ่มที่ 5 บรรทัด กด "เพิ่ม 5 บรรทัด" ได้ไม่จำกัด ช่อง **รหัสสินค้า** พิมพ์รหัส ชื่อ บาร์โค้ด หรือรุ่นรถ แล้วเลือกจากรายการแนะนำ (ลูกศรขึ้น-ลง + Enter หรือพิมพ์รหัสเต็มแล้ว Enter) ระบบเติมชื่อและราคาตามประเภทลูกค้าให้ ส่วนค่าแรง/บริการพิมพ์ชื่อในช่อง "รายการ" ได้โดยตรง · เลือกลูกค้า (หรือเพิ่มใหม่) เลือกรถ (หรือเพิ่มคันใหม่) กรอกเลขไมล์ อาการ แล้วเพิ่มรายการ: **อะไหล่** ค้นจากคลังสินค้า (ราคาอัตโนมัติตามประเภทลูกค้า) · **ค่าแรง** พิมพ์เองหรือเลือกจากรายการค่าแรงที่ใช้บ่อย · **อื่นๆ**
2. พิมพ์ใบเสนอราคา A4 ส่งลูกค้า → กด **ลูกค้าอนุมัติ** เมื่อตกลง (มีวันยืนราคา ถ้าเลยจะขึ้นป้ายหมดอายุ)
3. **รับรถ** ระบบออกเลขใบรับรถ (JO…) บันทึกเลขไมล์ สภาพรถ/ของในรถ/ตำหนิ ช่างผู้รับผิดชอบ และวันนัดรับรถ พิมพ์ใบรับรถให้ลูกค้าเซ็นได้
4. **เริ่มซ่อม → ซ่อมเสร็จ** งานขึ้นบอร์ด "งานในอู่" 3 ช่อง (รับรถแล้ว / กำลังซ่อม / ซ่อมเสร็จรอรับรถ) งานที่เลยวันนัดจะขึ้นป้ายแดง และระบบแจ้งเตือนเมื่อซ่อมเสร็จ
5. **ออกบิล / รับเงิน** เลือกวิธีชำระ (เงินสด โอน PromptPay บัตร เครดิต) หรือชำระบางส่วน ระบบสร้างบิลขาย ตัดสต็อกเฉพาะอะไหล่ (ค่าแรงไม่ตัดสต็อก) ลงบัญชีอัตโนมัติ และเปิดใบเสร็จทันที
6. กด **รับรถ / เปิดงานซ่อม** ได้โดยตรงถ้าไม่ต้องเสนอราคาก่อน
- ทุกขั้นตอนบันทึก "ประวัติเอกสาร" (ใคร ทำอะไร เมื่อไร แก้ค่าอะไรจากอะไรเป็นอะไร) และลงบันทึกตรวจสอบของระบบ
- เอกสารที่ออกบิลแล้วแก้ไขรายการไม่ได้ แก้ได้เฉพาะเงื่อนไขรับประกัน/นัดหมาย (ปุ่ม "รับประกัน / นัดหมาย") ซึ่งบันทึกประวัติทุกครั้ง
- ยกเลิกต้องระบุเหตุผล งาน CRM ที่ผูกกับเอกสารนั้นจะปิดให้อัตโนมัติ

### 10.3 ใบเสร็จงานซ่อม
- ใบเสร็จ (ทั้งแบบย่อและใบกำกับภาษีเต็มรูป A4) ของบิลที่มาจากงานซ่อมจะมีส่วนเพิ่ม: เลขใบรับรถ ทะเบียนรถ เลขไมล์ ช่าง **เงื่อนไขการรับประกัน** และบรรทัด **นัดหมายบริการครั้งต่อไป** (วันที่ และ/หรือ เลขไมล์)
- ข้อความรับประกันเริ่มต้นตั้งที่ **ตั้งค่า → ร้าน → การ์ด "อู่ซ่อมรถ / งานบริการ และ CRM"** และแก้เป็นรายใบได้ในฟอร์ม

### 10.4 CRM ติดตามลูกค้า
- **วันนี้**: งานเกินกำหนด งานครบกำหนดวันนี้ และ 7 วันข้างหน้า กด **เสร็จ** (บันทึกผลการติดต่อ) หรือ **เลื่อน** ได้ทันที กดเบอร์โทรเพื่อโทรจากมือถือ
- **สร้างอัตโนมัติ** เมื่อออกบิลงานซ่อม: งาน "ติดตามหลังซ่อม" (ค่าเริ่มต้น 3 วันหลังออกบิล) และ "เตือนนัดบริการครั้งถัดไป" (ล่วงหน้า 7 วันก่อนวันนัด หรือ 150 วันถ้าระบุเฉพาะเลขไมล์) ปรับจำนวนวันได้ในตั้งค่า แก้วันนัดในเอกสารแล้วงานเตือนจะเลื่อนตาม
- **บันทึกการติดต่อ** ทุกครั้งที่โทร/แชท/ลูกค้าเข้ามา (ไม่ใส่วันกำหนด = บันทึกเป็นเสร็จทันที)
- **ลูกค้า 360°**: แบ่งกลุ่มอัตโนมัติ (ใหม่ ประจำ เสี่ยงหาย 90–180 วัน หายไป >180 วัน ยังไม่เคยซื้อ) พร้อมยอดซื้อ 12 เดือน รถในทะเบียน นัดถัดไป งานค้าง กดเปิดไทม์ไลน์รวม บิล งานซ่อม และการติดต่อทั้งหมด
- **ประวัติการติดต่อ**: ทุกรายการมีผู้สร้าง ผู้ปิดงาน เวลา และ "บันทึกการแก้ไข" (เลื่อนกำหนด เปลี่ยนผู้รับผิดชอบ ฯลฯ) ตรวจสอบย้อนหลังได้ และส่งออก CSV ได้
- **สรุป**: ลูกค้าใหม่เดือนนี้ กลุ่มเสี่ยงหาย กิจกรรมตามประเภท งานค้างตามผู้รับผิดชอบ และรายชื่อนัดบริการใน 30 วัน

### 10.5 สิทธิ์
- บทบาทใหม่ **ช่างซ่อม** (technician) เห็นเมนู แดชบอร์ด ใบเสนอราคา/ใบรับรถ ลูกค้า สินค้า สต็อก CRM ห้องเรียน บุคคล
- แคชเชียร์ ผู้จัดการสาขา ฝ่ายบัญชี ฝ่ายการตลาด ใช้เมนูใบเสนอราคา/ใบรับรถ และ CRM ได้ ปรับรายเมนู/แท็บได้ที่ บุคคล → สิทธิ์การใช้ระบบ

## 11. งานรับประกัน / เคลม (เมนู งานรับประกัน / เคลม)

ใช้เมื่อรถที่ซ่อมไปแล้วกลับมาเคลม หรืออะไหล่ที่ขายไปเสียในระยะรับประกัน ลูกค้าไม่ต้องจ่ายเงิน แต่ระบบต้องตัดสต็อก บันทึกค่าใช้จ่าย และเคลมต่อผู้จำหน่ายได้

### 11.1 ขั้นตอน
1. **รับเรื่องเคลม** กด "รับเรื่องเคลม" (หรือจากหน้างานซ่อมที่ออกบิลแล้ว กดปุ่ม "เคลม") เลือกงานซ่อมเดิม ระบบดึงลูกค้า รถ และตรวจเงื่อนไขรับประกันให้ทันที (อยู่ในประกัน / เกินกี่วัน / วิ่งเกินกี่กม.) กรอกเลขไมล์ปัจจุบัน อาการที่แจ้ง และรายการอะไหล่/ค่าแรงที่จะทำให้ฟรี (กด "นำรายการจากงานซ่อมเดิม" ได้)
2. **ตรวจสอบและอนุมัติ** ผู้จัดการสาขาขึ้นไปกด "อนุมัติเคลม" (บันทึกผลตรวจ และเลือกว่าตามเงื่อนไข หรือดูแลพิเศษนอกเงื่อนไข) หรือ "ไม่รับเคลม" (ระบุเหตุผล แล้วกด "ออกใบเสนอราคา" เพื่อซ่อมแบบคิดเงินได้ทันที)
3. **ปิดงาน** กด "ปิดงาน: เบิกอะไหล่/ลงบัญชี" ระบบจะ
   - ตัดสต็อกอะไหล่ออกจากสาขา (ประเภทการเคลื่อนไหว "เบิกงานรับประกัน") โดยไม่สร้างบิลขาย ลูกค้าชำระ 0 บาท
   - ลงบัญชีอัตโนมัติ เดบิต 5130 ค่าใช้จ่ายงานรับประกัน / เครดิต 1140 สินค้าคงเหลือ ตามต้นทุนจริงของล็อตที่เบิก (ค่าแรงบันทึกเป็นต้นทุนภายในสำหรับสถิติ ไม่ลงบัญชี)
   - สร้างงานติดตามหลังเคลมใน CRM
   - ถ้าผู้ทำรายการไม่ใช่ผู้จัดการ ระบบส่งขออนุมัติปิดงานไปที่ เอกสาร & อนุมัติ ก่อนจึงมีผล
4. **เคลมผู้จำหน่าย** (ถ้าอะไหล่เคลมต่อได้) กด "ส่งเคลมผู้จำหน่าย" เลือกผู้จำหน่ายและรายการ พิมพ์ "ใบส่งเคลมผู้จำหน่าย" แนบไปกับของ เมื่อได้ผลกด "บันทึกผลจากผู้จำหน่าย"
   - **ให้เครดิต/ใบลดหนี้**: ระบบลงบัญชี เดบิต 2110 เจ้าหนี้การค้า / เครดิต 5130 และบันทึกเป็นรายการเครดิตในเจ้าหนี้ (สถานะ "credit") เพื่อนำไปหักกับใบแจ้งหนี้ถัดไปของผู้จำหน่าย
   - **ส่งของทดแทน**: รับเข้าสต็อกด้วยใบรับสินค้าปกติ ต้นทุน 0
   - **ปฏิเสธ**: บันทึกเหตุผลไว้เป็นหลักฐาน

### 11.2 เอกสารและการตรวจสอบย้อนหลัง
- พิมพ์ **ใบรับงานรับประกัน** (ลูกค้าเซ็นรับรถคืน แสดง VIN เลขไมล์ งานซ่อมเดิม เงื่อนไขรับประกัน รายการที่เปลี่ยนให้ มูลค่าที่ลูกค้าชำระ 0) และ **ใบส่งเคลมผู้จำหน่าย** (รายการ ล็อต ต้นทุน อาการเสีย)
- ทุกขั้นบันทึก "ประวัติเอกสาร" และบันทึกตรวจสอบของระบบ (claim.*) แก้ไขได้เฉพาะก่อนปิดงาน ยกเลิกต้องระบุเหตุผล
- หน้าสรุปแสดงงานเคลมค้าง ค่าใช้จ่ายรับประกันเดือนนี้ และเครดิตที่ได้คืนจากผู้จำหน่าย แท็บ "เคลมผู้จำหน่าย" ติดตามเรื่องที่รอผล
- ตั้งระยะรับประกันที่ใช้ตรวจเคลม (เดือน / กม.) ได้ที่ ตั้งค่า → ร้าน → การ์ด "อู่ซ่อมรถ / งานบริการ และ CRM"
